# UltimatePauser
This is the Ultimate Games/Apps Pauser for unpausable apps!

# Why do you need it?
Ever played games that can't be paused during cutscenes? (*GTA 4, wink wink*). Well, don't worry! This app came to the rescue!

I made this app to sharpen my skills in Python, libraries, and logic, so I'm proud that the world will be using it soon.

The app will be available in a terminal version soon, and then upgraded to a standalone `.exe` app using the Tkinter library.
